Traditional Dual-Controller Switching

[CC Loop PI] ──┘
  • ❌ Hard Switch Discontinuity: Employs two separate PI controllers with binary handover multiplexer.
  • ❌ Integrator Windup Spikes: Inactive CV integrator accumulates error during CC mode, releasing a violent +1.8A to +2.5A current surge upon transition.
  • ❌ Voltage Bounce: Creates transient overshoot and settling delays (> 15 ms).
PROPOSED NOVELTY (Our Work)

Inherent Soft-Clamped Cascade Control

[Outer V-Loop] ──> [SOFT-CLAMP (1.5A)] ──> [Inner I-Loop] ──> [PWM Duty]
                          ▲
                (Continuous Saturation)
  • ✅ Unified Cascade Hierarchy: Single continuous control structure without any discrete mode switches or state resets.
  • ✅ Inherent Soft Clamping: CC mode is natural saturation of the outer loop ($I_{ref} = \min(I_{raw}, 1.5\text{A})$); CV mode resumes smoothly when load drops.
  • ✅ 100% Bumpless: Exactly 0.00A current spike, zero voltage bounce, and fast < 2.5 ms monotonic settling.

⏱️ Outer Voltage Loop (Slow / Strategic)

  • Sampling Frequency: 1 kHz (Every 1 ms)
  • Primary Task: Compares output voltage Vout against target Vref.
  • Output Command: Target inductor current reference Iref.
  • Safety Protection: Hard software clamp on Iref prevents MOSFET thermal destruction during short circuits.

⚡ Inner Current Loop (Fast / Tactical)

  • Sampling Frequency: 10 kHz (Every 100 µs in Timer 1 ISR)
  • Primary Task: Measures instantaneous inductor current IL, compares with Iref.
  • Output Command: Hardware Timer OCR1A PWM register duty cycle.
  • Bandwidth Advantage: Absorbs input voltage spikes and sudden load changes instantly.
