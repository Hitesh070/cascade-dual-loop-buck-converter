Outer Voltage Loop (Slow / Strategic)

  • Sampling Frequency: 1 kHz (Every 1 ms)
  • Primary Task: Compares output voltage Vout against target Vref.
  • Output Command: Target inductor current reference Iref.
  • Safety Protection: Hard software clamp on Iref prevents MOSFET thermal destruction during short circuits.

Inner Current Loop (Fast / Tactical)

  • Sampling Frequency: 10 kHz (Every 100 µs in Timer 1 ISR)
  • Primary Task: Measures instantaneous inductor current IL, compares with Iref.
  • Output Command: Hardware Timer OCR1A PWM register duty cycle.
  • Bandwidth Advantage: Absorbs input voltage spikes and sudden load changes instantly.

System Modeling & Frequency Analysis (~10 Hours)

Stage 2

Hardware Assembly & Open-Loop Verification (~15 Hours)

Assemble power stage with IRF540N MOSFET, 1N5822 Schottky diode, 100µH inductor, 470µF capacitor, and IR2104 gate driver. Perform open-loop PWM test at 30% duty cycle to verify 3.6V output.

Schematic & BOM Complete
Stage 3

Microcontroller Firmware (Arduino Uno C Code) (~15 Hours)

Implement deterministic 10 kHz Timer 1 ISR interrupt for inner loop current control, anti-windup PI accumulators, soft-start reference ramping, and 1.5A current clamping.
