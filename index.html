Outer Voltage Loop (1 kHz)

  • Sampling Rate: Every 1.0 ms
  • Task: Compares output voltage Vout against target Vref.
  • Output: Generates target reference current command Iref.
  • Safety: Hard software saturation on Iref prevents overcurrent damage during short circuits.

Inner Current Loop (10 kHz)

  • Sampling Rate: Every 100 µs (Timer 1 ISR on Arduino Uno)
  • Task: Tracks actual inductor current IL against Iref command.
  • Output: Updates PWM duty cycle register directly.
  • Advantage: Reacts 10x faster than voltage loop, rejecting input line and load disturbances.
